# 🚚 Система доставок и движения товаров

## Новая функциональность

### 1. **Роль курьера**
- Добавлена роль `courier` в систему пользователей
- Курьеры могут просматривать назначенные им задания
- Отчитываются о выполнении доставок через приложение

### 2. **Управление доставками**
- Создание заданий на доставку (менеджер → курьер)
- Выбор места доставки: Ozon, Wildberries, Яндекс.Маркет, или произвольный адрес
- Указание товаров, количества и стоимости доставки
- Отслеживание статусов: Ожидает → В пути → Доставлено/Не доставлено

### 3. **Движение товаров**
- Автоматическое списание товаров при продаже
- Резервирование товаров при создании доставки
- Возврат товаров при неудачной доставке
- Полная история движений каждого товара

### 4. **Новые экраны**
- **Доставки** — новая вкладка в приложении
- **Детальный просмотр товара** — с историей движений
- **Создание задания на доставку**
- **Отчёт курьера о доставке**

---

## 📱 Пользовательские сценарии

### Менеджер создаёт доставку:
1. Переходит на вкладку "Доставки"
2. Нажимает "+" для создания задания
3. Выбирает курьера из списка
4. Указывает место доставки (Ozon/WB/Яндекс/другое)
5. Добавляет товары с количеством и стоимостью доставки
6. Создаёт задание → товары автоматически списываются со склада

### Курьер выполняет доставку:
1. Видит назначенные задания в приложении
2. Нажимает "Начать доставку" → статус меняется на "В пути"
3. После доставки нажимает "Отчитаться о доставке"
4. Заполняет заметки о результате
5. Отмечает "Доставлено" или "Не доставлено"

### Отслеживание товаров:
1. На экране товаров нажимает "Подробнее"
2. Видит текущий остаток и историю движений
3. Каждое движение показывает: тип, количество, причину, дату

## 🗂️ Структура данных

### Доставка (`IDeliveryTask`)
```typescript
{
  id: string
  taskNumber: "DEL-2026-123456"
  courierId: string
  courierName: string
  destination: 'ozon' | 'wildberries' | 'yandex_market' | 'custom'
  destinationAddress: string
  items: [
    {
      productId: string
      productName: string
      quantity: number
      price: number // стоимость доставки за единицу
      totalCost: number
    }
  ]
  status: 'pending' | 'in_transit' | 'delivered' | 'failed'
  createdAt: string
  deliveredAt?: string
  notes?: string
}
```

### Движение товара (`IInventoryMovement`)
```typescript
{
  id: string
  productId: string
  productName: string
  movementType: 'sale' | 'delivery_out' | 'delivery_in' | 'return' | 'adjustment'
  quantity: number // + приход, - расход
  previousQuantity: number
  newQuantity: number
  relatedId?: string // ID продажи/доставки
  reason: string
  timestamp: number
  date: string
}
```

## 🔧 Техническая реализация

### Новые хуки:
- `useDeliveries()` — управление доставками
- `useInventoryMovements()` — отслеживание движений товаров

### Новые компоненты:
- `CreateDeliveryTask` — форма создания доставки
- `CourierDeliveryReport` — отчёт курьера
- `ProductMovements` — история движений товара

### Обновлённые хуки:
- `useSalesActions()` — теперь списывает товары и записывает движения
- `useDeliveries()` — резервирует/возвращает товары при доставке

### Firebase коллекции:
```
users/{uid}/
├── deliveries/          # задания на доставку
├── inventory_movements/ # движения товаров
├── products/           # товары (обновляется quantity)
├── sales/              # продажи
└── ...
```

## 🎯 Интеграция с существующим функционалом

### Продажи:
- При создании продажи автоматически уменьшается `quantity` товара
- Записывается движение типа `sale`
- Связывается с ID продажи через `relatedId`

### Товары:
- Новая кнопка "Подробнее" открывает детальный экран
- Показывает историю всех движений товара
- Предупреждает о низком остатке (≤5 шт)

### Мониторинг:
- Статистика учитывает реальные остатки товаров
- График продаж связан с движениями товаров
