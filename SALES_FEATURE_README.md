# ✅ График продаж добавлен на страницу мониторинга

## Что было добавлено:

### 1. **График продаж на экране мониторинга**
- Линейный график, показывающий количество товаров, проданных за последние 8 часов
- Адаптирована цветовая гамма ваше приложения:
  - Основной цвет (красный): `#BF3335` для линии графика
  - Фон: `#282828` (серый)
  - Текст: белый

### 2. **Статистика продаж за сегодня**
- Количество проданных товаров
- Общая сумма продаж

### 3. **Быстрое добавление продажи товара**
На странице товаров появилась кнопка **"Продать"** для каждого товара:
- Нажмите кнопку "Продать" рядом с товаром
- Введите количество единиц для продажи
- Система подсчитает общую стоимость
- Продажа сохранится в Firebase и автоматически отобразится на графике

## Структура данных:

### Новые файлы типов:
- `shared/types/sales.types.ts` - типы для продаж

### Новые хуки:
- `components/Products/hooks/useSales.ts` - получение данных о продажах и подсчёт статистики
- `components/Products/hooks/useSalesActions.ts` - добавление новых продаж в Firebase

### Новые компоненты:
- `components/Products/QuickSaleModal.tsx` - модальное окно для быстрого добавления продажи

## Как это работает:

1. **Добавление продажи:**
   - При нажатии кнопки "Продать" открывается модальное окно
   - Вводится количество товара
   - Данные сохраняются в Firebase коллекцию `users/{uid}/sales`

2. **Отображение графика:**
   - Хук `useSales` подсчитывает продажи по часам за последние 8 часов
   - График обновляется динамически при добавлении новой продажи
   - Используется библиотека `react-native-chart-kit` для визуализации

3. **Структура продажи в Firebase:**
   ```
   {
     productId: string      // ID товара
     productName: string    // Название товара
     quantity: number       // Количество проданных единиц
     price: number          // Цена за единицу
     totalAmount: number    // Общая сумма
     timestamp: number      // Время продажи (миллисекунды)
     date: string           // Дата продажи (YYYY-MM-DD)
   }
   ```

## Установленные зависимости:
- `react-native-chart-kit@6.12.0` - для отображения графиков

## Интеграция с вашей системой:

Продажи будут автоматически:
- Записываться при добавлении
- Отображаться на графике в реальном времени
- Учитываться в статистике по часам
- Связываться с конкретным товаром через `productId`

Всё готово к использованию! Просто открывайте приложение и начинайте продавать товары через кнопку "Продать" на странице товаров.
